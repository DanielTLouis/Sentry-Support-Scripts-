# Running the ASentry Base Configuration Setup for Linux Servers

To run the **ASentry Base Configuration Setup** for Linux servers with the openSUSE distribution of Linux, follow the steps below.

1. Navigate to the **BaseConfigDocs** directory on the server. The `run_base_config.sh` script should be located in the same directory as this document.

2. Run the following command:

```bash
./run_base_config.sh
```

3. Follow the on-screen menu to select the components you want to install or configure.

Each menu option can be run independently. To perform a complete server setup, run every available option.

> **Note:** These scripts may exhibit unexpected behavior or fail on **openSUSE Leap 16**, as they have not yet been updated to support the latest operating system version.
